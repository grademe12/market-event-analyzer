# Classifier evaluation fixtures

These cases are synthetic and exist to compare model behavior, structured-output reliability, latency, and cost.

They are not investment labels or claims about real companies. Direction labels express the intended simulated participant reaction for clearly constructed test scenarios.

The first model comparison should score at least:

- structured output validity
- direction agreement with `acceptable_directions`
- impact agreement
- latency
- estimated cost per analyzed item

Confidence is intentionally not given a fixed target because it is model-calibration dependent.
